# Manual de Identidad de Marca — UNO COMPRAS

---

## 1. Esencia de marca *(lo que la define)*

* **Qué es:** Una marca de e-commerce para vender por internet de forma simple, confiable y moderna.
* **Propósito:** Hacer que comprar online sea una experiencia clara, rápida y accesible.
* **Personalidad:** Cercana, ágil, moderna, confiable y simple.
* **Valores:** Confianza, simplicidad, rapidez, claridad y servicio.
* **Público objetivo:** Personas en Argentina que compran online y valoran practicidad, buen precio y una experiencia de compra fácil.
* **Posicionamiento:** Una marca digital directa, visualmente limpia y pensada para inspirar confianza en cada compra.

> **Idea clave:** El sistema debe transmitir simplicidad, confianza y modernidad en todo momento.

---

## 2. Sistema de logotipo *(cómo se usa la marca)*

El sistema establece reglas claras para la aplicación correcta del logotipo:

### Versiones
* **Versión principal:** Logotipo completo (`UNO` + ícono de bolsa + `COMPRAS`). Es la opción preferida.
* **Versión horizontal:** Para espacios reducidos en altura.
* **Isotipo / Ícono:** Para formatos pequeños, favicon, app y elementos gráficos complementarios.

### Reglas de construcción y aplicación
* **Construcción visual:** Tipografía geométrica, composición limpia y símbolo integrado al universo de compra online.
* **Margen mínimo de seguridad:** Dejar un margen equivalente a la altura de la letra **«O»** alrededor de todo el logotipo.
* **Tamaño mínimo:**
  * **Digital:** $120\text{ px}$ de ancho.
  * **Impresión:** $25\text{ mm}$ de ancho.

### Usos incorrectos
* ❌ No deformar.
* ❌ No cambiar proporciones.
* ❌ No aplicar efectos (sombras, degradados no oficiales, biseles).
* ❌ No alterar los colores oficiales.

> **Idea clave:** El logotipo debe usarse de forma consistente para fortalecer el reconocimiento de marca.

## 3. Paleta y tipografía *(los elementos visuales)*

### Paleta de colores oficiales

| Color | Código Hex | Rol / Aplicación |
| :--- | :--- | :--- |
| **Naranja principal** | `#FF6A00` | Énfasis principal, llamadas a la acción, acentos de energía |
| **Turquesa principal** | `#18D6D1` | Color complementario, frescura, detalles dinámicos |
| **Negro carbón** | `#151515` | Textos principales, fondos oscuros, contraste |
| **Gris claro** | `#F3F3F3` | Fondos neutros, tarjetas, separadores |
| **Gris medio** | `#8A8A8A` | Textos secundarios, bordes, estados inactivos |

### Tipografías
* **Titulares:** Montserrat Bold
* **Apoyo / Subtítulos:** Montserrat Medium
* **Textos de lectura:** Inter Regular
* **Estilo general:** Limpio, geométrico y altamente legible.

> **Idea clave:** La paleta y tipografía deben comunicar frescura, accesibilidad y modernidad.

---

## 4. Identidad verbal *(cómo habla la marca)*

* **Tono de voz:** Claro, directo, confiable y cercano.
* **Cómo comunica:** Con mensajes simples, beneficios concretos y llamados a la acción claros.

### Frases de marca
* *«Comprá fácil.»*
* *«Todo lo que necesitas, más cerca.»*
* *«Elegí, comprá y recibí.»*
* *«Simple, rápido y confiable.»*

### Llamados a la acción (CTAs)
* Comprá ahora →
* Descubrí ofertas →
* Sumalo al carrito →
* Aprovechá hoy →

### Estilo recomendado
Usar lenguaje simple, visualmente ordenado y orientado a generar confianza.

> **Idea clave:** Las palabras también construyen marca; deben ser simples, claras y confiables.
